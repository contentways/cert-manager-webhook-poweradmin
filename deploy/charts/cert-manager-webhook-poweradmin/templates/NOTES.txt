The webhook serves the API group {{ .Values.groupName }} with the solver "poweradmin".

Store the Poweradmin API key in a Secret next to the issuer and reference the solver:

  kubectl create secret generic poweradmin-api-key --namespace <issuer namespace> --from-literal=api-key=<key>

  solvers:
    - dns01:
        webhook:
          groupName: {{ .Values.groupName }}
          solverName: poweradmin
          config:
            baseURL: https://dns.example.com
            apiKeySecretRef:
              name: poweradmin-api-key
              key: api-key
